# Heart Disease Prediction ML

Predict heart disease using classification models (Logistic Regression and Random Forest).

## Dataset
- data/heart_disease.csv - Contains patient features and target (heart disease presence)

## Notebooks
- 
otebooks/heart_disease_prediction.ipynb - EDA, preprocessing, classification models, ROC-AUC, confusion matrix, and feature importance

## Installation
`ash
pip install -r requirements.txt
`

## Usage
Run the notebook in Jupyter/VSCode to explore and predict heart disease.
